# Maranzetor

Un anno scolastico da maranza nel quartiere, nel 1997 o nel 2026. Gioco browser isometrico illustrato, omaggio a Tabboz Simulator di Andrea Bonomi (1997).

Gioca: https://ilgabbah-ux.github.io/maranzetor/

Su Android: apri il link in Chrome e scegli "Installa app" (o "Aggiungi a schermata Home"). Funziona anche offline.

Un gioco di Gabbah Productions.
